PsyR

PsyR utilises procedures described by Bird (2002) to compute simultaneous confidence intervals for planned and post-hoc contrasts from ANOVA models. Simultaneous confidence intervals give a researcher greater insight into the magnitude of an effect captured by a contrast. This can allow for more nuanced interpretation of results with respect to directionality and effect size.

Installation

PsyR is currently a development package and is not yet available on CRAN. Install it from GitHub:

install.packages("pak") # Run once to install the installer.
pak::pak("garner-code/PsyR")

The development version may contain bugs. Installation requires internet access and access to the GitHub repository; a private repository requires an authorised GitHub account. PsyR’s required R package dependencies are installed automatically, although some dependencies may require system libraries or build tools when installed from source.

install.packages("PsyR") will work with CRAN only after a release has been submitted, accepted, and made available on CRAN and its mirrors.

Classic Workflow

An average workflow will go as follows:

  • Load data, tidy into longform.

  • Use afex::aov_ez() to generate an ANOVA model.

  • Use emmeans::emmeans() to obtain estimated marginal means.

  • Specify user-defined contrast coefficients and use PsyR::rescale_contrasts() to scale them as mean-difference contrasts (mode = "mean_difference") or interaction contrasts (mode = "interaction", with the appropriate interaction_order). Match the coefficient order to the estimated marginal means. When crossing mean-difference components with emmeans::contrast(), their products already have the appropriate interaction scaling.

  • Use emmeans::contrast() to generate statistical output pertaining to each contrast.

  • Use psyci() to generate simultaneous confidence intervals.

Example

Within-subject ("w") and between-by-within ("bw") families require multivariate emmeans contrast tables. psyci() checks the supplied objects and stops if their basis is univariate or cannot be established, including with family_check = "warn" or "none". Between-subject families do not have this new restriction. Use check_emmeans_model() to check tables separately.

Changing afex_options(emmeans_model = "multivariate") does not update existing tables. Recreate the marginal means and contrasts with the original definitions and analysis settings, explicitly selecting the multivariate model. The fitted ANOVA normally does not need to be re-estimated. For example:

data("spacing", package = "PsyR")
model <- afex::aov_ez(
  "subj", "yield", spacing, within = "spacing", between = "group"
)
definitions <- list("Twenty - Forty" = c(1, -1, 0))
# Rebuild from the fitted ANOVA, preserving any original weights/by/at settings.
means <- emmeans::emmeans(model, "spacing", model = "multivariate")
contrasts <- emmeans::contrast(means, definitions, adjust = "none")
diagnostics <- PsyR::check_emmeans_model(model, contrasts)
result <- PsyR::psyci(model, contrasts, method = "individual")

psyci() results now use df1, df2, p_adj, and method as both stored column names and printed headings. This is a breaking change: code using df_num, df_error, p_value_adjusted, or p_adjustment must use the new names. The unadjusted p_value and polynomial indicator remain stored but are hidden when printing. Printed families are labelled between, within, and mixed; interaction component labels share one printed contrast column.

Below are some basic examples showing how to obtain simultaneous confidence intervals. The main examples use the post-hoc method; the optional Algina–Keselman example uses Bonferroni intervals. See (Bird 2002) for details. Also, check out the “Articles” tab for detailed examples of analysis pertaining to various designs.

## load relevant packages
library(emmeans)
library(afex)
library(PsyR)

# load some data
dat <- spacing

# set emmeans option to multivariate
afex_options(emmeans_model = "multivariate")

# perform the statistical model
mod <- aov_ez("subj", "yield", dat, within = "spacing", between = "group")

# define and mean-difference scale some between-group contrasts
emm_btwn <- emmeans(mod, "group")
raw_con_b <- list(
  "12vs34" = c(1, 1, -1, -1), # groups 1 & 2 vs groups 3 & 4
  "1vs2" = c(1, -1, 0, 0),    # group 1 vs group 2
  "3vs4" = c(0, 0, 1, -1)     # group 3 vs group 4
)

#mean difference scale contrasts, then produce and store statistical output
con_b <- rescale_contrasts(raw_con_b, mode = "mean_difference")
btwn_con <- contrast(emm_btwn, con_b)

# feed the contrast table into psyci(); its family and participating factors
# are inferred from the model and the original emmGrid
result <- psyci(
  model = mod, 
  contrast_tables = list(btwn_con), 
  method = "ph"
)

1vs2 -14.083 2.992 1 12 22.155 0.005 10.471 * -23.765 -4.401
3vs4 -2.500 2.992 1 12 0.698 0.872 10.471 -12.182 7.182

psyci() prints all contrasts in two combined tables, each with a family column (between, within, or mixed). The first table reports the contrast effects and confidence intervals in the dependent variable’s original units. The second reports the same values in sample standard-deviation units, using the pooled within-cell scaling method from the original Psy program (Bird 2002). Numeric values print to three decimal places, and only PsyR’s adjusted p-value is shown (p_adj). F_crit replaces the critical constant column; sig shows * when the adjusted p-value is below the applicable alpha and is blank otherwise. The raw tables remain available through ordinary list indexing. For example:

result <- psyci(mod, list(btwn_con), method = "ph")
raw_table <- result[[1]]
scaled_table <- attr(result, "scaled_tables")[[1]]

1vs2 -3.045 0.647 1 12 22.155 0.005 10.471 * -5.138 -0.952
3vs4 -0.540 0.647 1 12 0.698 0.872 10.471 -2.634 1.553

It is possible to print Psy’s legacy layout for the supplied contrasts. This will contain values for each contrast’s sum of squares, degrees of freedom, mean squares error, and F statistic.

To print Psy’s legacy layout, set legacy_summary as TRUE within the psyci() call.

result <- psyci(
  mod,
  list(btwn_con),
  method = "ph",
  legacy_summary = TRUE
)
legacy_table <- attr(result, "legacy_anova_table")

Here is an example, that carries on from the last, for obtaining within-subjects confidence intervals:

# define and mean-difference scale some within-subject contrasts
emm_win <- emmeans(mod, "spacing")
raw_con_w <- list(
  "20vs40" = c(1, -1, 0),
  "20vs60" = c(1, 0, -1),
  "Quad" = c(1, -2, 1)
)
con_w <- rescale_contrasts(raw_con_w, mode = "mean_difference")
con_win <- contrast(emm_win, con_w)

# generate 95% CIs for the within subjects contrasts
win_result <- psyci(
  model = mod, 
  contrast_tables = list(con_win),
  method = "ph"
)

PsyR identifies polynomial contrasts from their coefficients and suppresses their confidence limits in both raw and standardized tables, while retaining their estimates and tests. In this example, both 20vs60 (equivalent to a linear trend over the three equally spaced levels) and Quad are flagged. Their stored lower and upper values are NA and print as blanks. This suppression is current PsyR behavior, rather than a requirement of the original Psy method.

For pairwise correlated within-subject means, PsyR also provides the asymmetric noncentral-t standardized-effect interval proposed by Algina and Keselman (2003). It is opt-in, so existing calls retain the original Psy/Bird output. Use it with individual or Bonferroni intervals:

result_ak <- psyci(
  mod,
  list(con_win),
  method = "bf",
  standardized_ci = "algina_keselman"
)
ak_table <- attr(result_ak, "scaled_tables")[[1]]

And finally, here is an example of how to generate CIs for between x within contrasts, using the same post-hoc method:

# get emms for each cell from the between x within design
emm_int <- emmeans(mod, c("group", "spacing"))

# emmeans forms products of the supplied between and within coefficients. It
# does not normalize those coefficients. Because con_b and con_w were each
# scaled above as order-0 mean differences, their products are correctly scaled
# order-1 interactions (differences between mean differences).

con_int <- contrast(emm_int, interaction=list(con_b, con_w))
# generate 95% CIs for the between x within subjects contrasts
psyci(
  model = mod, 
  contrast_tables = list(con_int), 
  method = "ph"
  )

The “contrast_tables” argument can also take in all stored contrasts within a base::list()

# enter contrast tables in one long list
psyci(
  model = mod, 
  contrast_tables = list(btwn_con, con_win, con_int), 
  method = "ph"
  )
