F-STP-and-Scheffe-CI-posthoc

A vignette to help understand how to use PsyR to enact the Scheffé technique, which uses an ANOVA F Simultaneous Test Procedure and Scheffé Simultaneous Confidence Interval (SCI) method for making inferences for multiple contrasts.

The Packages

To use Psy to calculate confidence intervals over contrast effects, we will use a workflow that uses functions from afex to implement ANOVA models, and emmeans to obtain estimated marginal means and the required contrast estimates. So let’s load those packages, and any others that are helpful for our workflow.

library(afex)
library(emmeans)
library(ggplot2)
library(PsyR)
library(tidyverse)

The Analysis

Lets prepare to run some statistical tests!

Here we will create the building blocks of our eventual ANOVA output. First, lets create a new object labelled mod (short for model). Call the aov_ez() function which takes in the “id” column to identify subjects, the “Errors” column as the dependent variable, the fatigue dataframe, and the “Group” column set as between-subjects. This aggregates across our Group column, so it isn’t useful on its own.

Next, lets create a new object emms (short for estimated marginal means) calling the emmeans() function and specifying that we want to take in mod (the object we just made) and output based upon “Group”. Now we are heading in the right direction, as our results are split by factor (“Alert”, “Mild”, “Moderate”, “Extreme”).

# perform the statistical model
mod <- aov_ez(
  "id",
  "Errors",
  fatigue,
  between = "Group"
)
#> Contrasts set to contr.sum for the following variables: Group
emms <- emmeans(mod, "Group")

Time to define our contrasts!

Lets create an object called between_contrasts. Next, call the list() function and define our four contrasts of interest. The contrasts represent the following:

  • “Fatigue-Alert” - The difference between the average of fatigued conditions and the alert condition

  • “Extreme-Mod, Mild” - The difference between Extreme fatigue and the average of Moderate and Mild fatigue.

  • “Low-High” - The difference between the average of Alert and Mild fatigue versus the average of Moderate and Extreme fatigue.

  • “Alert-Mild” - The difference between the Alert and Mild fatigue conditions.

### note to selves - is there a way to get emmeans to do the scaling here?
between_contrasts = list(
  "Fatigue-Alert" = c(-1, 1/3, 1/3, 1/3),
  "Extreme-Mod, Mild" = c(0, -1/2, -1/2, 1),
  "Low-High" = c(1/2, 1/2, -1/2, -1/2),
  "Alert-Mild" = c(1, -1, 0, 0)
)

Now that we have defined our contrasts, lets create our ANOVA table. Create the btwn_fx object, then call the contrast() function from the emmeans package, setting emms in the “object” argument and between_contrasts in the “method” argument (which will take in our newly defined contrasts).

btwn_fx <- contrast(emms, between_contrasts)

Finally, lets calculate some confidence intervals to estimate effect sizes. Lets create the list contrasts_w_cis using the psyci() function, specifying the following:

  • The model is the previously made mod object, where the model must be made using the afex package - afex_aov

  • The contrast_tables argument is set as the previously made btwn_fx

  • The family list is set as “b”, specifying that the contrast table is between-subjects only

  • The method is set as “ph”, creating confidence intervals (estimate +- SE x cc) using a post-hoc method (Bird 2002)

  • Alpha is set at 0.05, indicating the desired type I error rate

  • The between_factors argument is set according to our desired group names, as in the “Group” column

contrasts_w_cis <- psyci(
  mod,
  contrast_tables = list(btwn_fx),
  family_list = list("b"),
  method = "ph",
  alpha = .05,
  between_factors = list("Group")
)
knitr::kable(contrasts_w_cis, digits = 3)
contrast estimate SE df t.ratio p.value cc lower upper
Fatigue-Alert 6.0 1.070 40 5.606 0.000 2.918 2.877 9.123
Extreme-Mod, Mild 7.5 1.135 40 6.607 0.000 2.918 4.187 10.813
Low-High -7.0 0.927 40 -7.552 0.000 2.918 -9.705 -4.295
Alert-Mild -2.0 1.311 40 -1.526 0.135 2.918 -5.825 1.825

The Interpretation

There is evidence of significant differences in the “Fatigue-Alert”, “Extreme-Mod, Mild”, and “Low-Hi” contrasts (p < 0.05).

  • Compared to alert drivers, having any level of fatigue results in between 2.877 and 9.123 more driving errors.

  • Drivers with extreme fatigue make between 4.187 and 10.813 more errors than the average of Moderate and Mild fatigue conditions.

  • Drivers with low fatigue (the average of alert and mild conditions) make between 4.295 and 9.705 fewer errors than those with high fatigue (the average of moderate and extreme conditions)

There is insufficient evidence to suggest a significant difference exists in the “Alert-Mild” contrast (p > 0.05).

  • Alert drivers may make 5.825 fewer or 1.825 more mistakes than their mildly fatigued counterparts.

Bird, Kevin D. 2002. “Confidence Intervals for Effect Sizes in Analysis of Variance.” Educational and Psychological Measurement 62 (2): 197–226. https://doi.org/10.1177/0013164402062002001.
